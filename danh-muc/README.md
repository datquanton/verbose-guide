# Portfolio consultant (`/danh-muc/`)

An interactive page: the investor enters positions and views; the page returns sizing, concentration,
entry/exit and the evidence for and against from the site's reports. No server, no account; input stays in the browser.

| File | What | Refresh when |
|---|---|---|
| `research.js` | Evidence base: every claim is copied from a published report and names its source | a report is published or revised |
| `market.js` | Volatility, trend, beta, correlation, valuation for 77 tickers. Generated by `build_market.py` | every 1–2 weeks (the page warns after 14 days) |
| `engine.js` | Sizing and risk rules. Pure functions, runs in Node for testing | a rule changes |
| `i18n.js` | All interface text, Vietnamese and English | wording changes |
| `intake.js` | Reads a pasted list or a broker screenshot into ticker and weight rows; the parser runs in Node for testing | a broker layout is misread |
| `vendor/tesseract/` | Self-hosted text recognition, loaded only when a screenshot is chosen | upgrading the library |
| `app.js`, `app.css` | Interview, form and rendering | — |
| `OVERNIGHT.md` | Brief for unattended maintenance runs, with a run log | after each run |

Refreshing prices: pull ~260 adjusted daily closes per ticker (plus `VNINDEX`) from FiinQuantX, save the JSON responses, then
`python3 build_market.py prices*.json > market.js`. Valuation and liquidity figures are the `SNAP` table inside the script; update it and `SNAP_DATE` from the same day's snapshot.

Not generated by the site generator: the homepage card and nav link were added by hand to `/index.html` and `/en/index.html`.
