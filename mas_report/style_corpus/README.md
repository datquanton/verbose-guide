# Style corpus

Drop ~10 recent **Good Morning Vietnam** reports here as `.docx` files
(any filename). The commentary generator extracts only the market-commentary
text (headline + 3 paragraphs) from each and few-shots Claude on them so the
generated prose matches the desk's voice.

Numbers are never taken from these files — only tone, structure, and phrasing.
These files are git-ignored (confidential), so they stay local to your machine.
