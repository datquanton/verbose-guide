# Nghiên cứu cổ phiếu Việt Nam — website

This branch is the website. Every page lives in a section folder:

| Path | What |
|---|---|
| `/` and `/en/` | Homepages (Vietnamese, English), one heading per section |
| `/nganh/` | Industry reports: `chung-khoan-q3-2026/`, `sector-pulse-q3-2026/` (with `en/`) |
| `/ngan-hang/` | Banking updates: archive page and `updates/<date-slug>/` posts |
| `/ket-qua-kinh-doanh/` | Earnings reviews: `vn30-2q26/` (with its CSV) |
| `/sector-pulse-q3-2026/`, `/nganh-chung-khoan-q3-2026/` | Redirects only, for links shared before the move |

To add a report: put it in its section folder as `<slug>/index.html`, then add a card for it on both homepages and on the section page.
The homepages, section pages, VN30 page and redirects are generated by `build_site.py`, kept in the owner's research vault.
Personal research, not investment advice. Updated 2026-11-13.
